# IXseal UI/UX 설계

시안: [mockup/index.html](mockup/index.html). 디자인 합의용 초기 시안이며, 이후 바뀐 내용(VM 키 파일 항목, 파일 항목 유형 등)은 실제 구현(`ixseal/templates`, `ixseal/static`)이 기준이다.

## 1. 원칙

1. **한 화면 한 행동**: 고객 화면에는 행동 버튼이 하나만 있다(보기, 복사, 폐기). 엔지니어 화면도 주요 행동은 초록 버튼 하나로 제한한다.
2. **IXcloud의 서비스임이 드러나게**: 상단 오렌지 띠, IXseal 로고, 하단의 "IXcloud by KINX" 표기와 Cloud 헬프데스크 안내로, 처음 보는 링크도 피싱이 아니라는 신뢰를 준다.
3. **상태를 항상 보여준다**: 남은 시간, 폐기 방식, 열람 여부를 숫자와 배지로 늘 노출한다.
4. **되돌릴 수 없는 행동은 한 번 더 확인한다**: 폐기, 회수, 템플릿 변경(입력값 초기화) 전에 확인을 받는다.
5. **보이는 대로 보낸다**: 엔지니어는 등록·템플릿 편집 중에 고객이 볼 화면을 실시간으로 확인한다.

## 2. 색

헤더는 KINX 오렌지·차콜, 그 아래 본문은 KINX 상징색인 초록을 쓴다. 출처는 KINX 공식 사이트 CSS(`#FF620C`, `#242424`)와 IXcloud 콘솔(`#52BF8A`)이다.

| 영역 | 토큰 | 값 | 용도 |
| --- | --- | --- | --- |
| 헤더 | `--accent` | `#FF620C` | 로고 마크, "seal" 글자, 고객 화면 상단 3px 띠 |
| 헤더 | `--ink` | `#242424` | 관리 화면 상단바, 제목 글자 |
| 본문 | `--brand` | `#52BF8A` | IXcloud 콘솔 초록. 포커스 링, 선택 테두리, 남은 시간 막대, 섹션 표시 막대, 상태 점 |
| 본문 | `--brand-strong` | `#1E8556` | 주요 버튼 배경, 초록 글자 (흰 글자 대비 4.6:1, WCAG AA) |
| 본문 | `--brand-hover` | `#176B45` | 버튼 hover, 선택된 칩 글자 |
| 본문 | `--brand-soft` | `#EAF7F0` | 선택 카드·칩 배경, 아이콘 배경 |
| 공통 | `--ink-2` / `--ink-3` | `#464646` / `#6B6B6B` | 본문 / 보조 텍스트 |
| 공통 | `--line` / `--bg` | `#E5E5E2` / `#F6F6F4` | 테두리 / 페이지 배경 |
| 상태 | `--warn` / `--warn-soft` | `#8A5300` / `#FFF5E0` | 비밀번호 변경 안내, 1회 열람 배너, 만료 임박 |
| 상태 | `--danger` / `--danger-soft` | `#C5221F` / `#FDECEA` | 폐기, 회수, 필수 표시 |
| 상태 | `--info` / `--info-soft` | `#1A5FB4` / `#E8F1FD` | '대기' 배지 |

- 콘솔 초록 `#52BF8A`에 흰 글자를 올리면 대비가 2.3:1로 읽기 어렵다. 그래서 버튼에는 같은 계열의 진한 `#1E8556`을 쓰고, `#52BF8A`는 선·점·막대에 쓴다.
- 모서리: 카드 12~14px, 입력·버튼 8px, 배지 999px
- 간격: 4px 단위

## 3. 타이포

- 본문: **Pretendard** (OFL, VM에서 직접 제공, 동적 서브셋). 대체 글꼴: Apple SD Gothic Neo, Malgun Gothic
- 계정 값: `ui-monospace, "D2Coding", Consolas` 15px. 0/O, l/1을 구분하기 쉽다.
- 크기: 제목 22/19, 본문 15, 보조 13, 배지 12. 숫자는 `tabular-nums`

## 4. 고객 화면 (모바일 우선, 카드 최대 폭 520px)

| 화면 | 구성 |
| --- | --- |
| 안내 | 방패 아이콘 → "○○ 님께 전달된 계정정보" → 제목 → 보낸 사람·열람 기한(남은 시간)·열람 방식 → 방식 안내 → [계정정보 보기] |
| 열람 | 제목·남은 시간 → **섹션별 묶음**(초록 막대 + 섹션 제목) → 반복 섹션은 카드("VM 1 · web-01") → 섹션 안내문 → 첨부 파일 → (확인형) [확인 완료 · 지금 폐기] |
| 1회 열람 | 열람 화면 위에 주황 배너: "이미 폐기 처리됨 · 창을 닫으면 다시 볼 수 없음 · 파일 받기 09:41 남음" |
| 만료 | 회색 방패, "열람할 수 없는 링크입니다", 헬프데스크·담당 엔지니어에게 재발급 요청 안내 |
| **공통 하단** | 메일 아이콘 + "문의사항은 **Cloud 헬프데스크**(help_cloud@kinx.net)로 메일 보내 주세요." → "IXcloud by KINX" |

- 항목 값 오른쪽 버튼: 비밀은 [보기], URL은 [새 창 열기], 모두 [복사]
- 안내문(정보/주의) 안의 URL·메일 주소는 자동 링크

## 5. 엔지니어 화면 (데스크톱 1280px 기준, 1024px까지 대응)

- **상단바** (차콜): IXseal 로고 · [전달 목록] [새 전달] [템플릿] · 오른쪽에 환경 배지(DEV)와 담당자 이름
- **전달 목록**: 요약 숫자 4개 → 상태 탭 + 검색 → 표(제목 아래에 고객·템플릿·요청 번호)
- **새 전달** (왼쪽 입력, 오른쪽 420px 미리보기)
  1. 템플릿 칩 + [템플릿 관리] 링크. 바꾸면 기본 정보는 유지하고 항목만 다시 채운다(입력값이 있으면 확인).
  2. 기본 정보: 고객명, 요청 번호, 제목(템플릿 기본 제목), 담당자
  3. 섹션 카드: 항목 행(이름 | 값 | 가림 | 삭제), 비밀 값의 [생성], [항목 추가], 반복 섹션의 [VM 추가]/[이 VM 삭제], 고객 안내문(수정 가능)
  4. 첨부 파일
  5. 열람 설정: 기한 5단계, 폐기 방식 카드 3개 → 요약("폐기 예정 · 항목 · 파일 · 필수 n개 미입력") + [봉인하고 링크 만들기]
- **미리보기**: 휴대폰 모양 틀 + 주소줄(`seal.ixcloud.net/s/••••`), [안내 | 열람] 전환. 안내 화면의 [계정정보 보기]를 누르면 열람으로 넘어간다.
- **템플릿 목록**: 카드(이름, 사용 횟수, 설명, 섹션 구성 칩, 기본 기한·방식, 수정일·수정자, [복제] [편집]) + "새 템플릿 만들기" 점선 카드
- **템플릿 편집** (왼쪽 편집, 오른쪽 미리보기)
  - 템플릿 정보: 이름, 기본 제목, 설명, 기본 열람 기한, 기본 폐기 방식
  - 섹션 카드: 번호 · 제목 · [여러 개] 토글 + 단위 · 위/아래 · 삭제
  - 항목 행: 이름 | 유형(텍스트/비밀/URL/여러 줄) | 기본값(비밀은 비활성) | 필수 | 위/아래 | 삭제
  - 안내문 행: 톤(안내/주의) | 본문 | 삭제
  - [항목] [안내문] 추가, 맨 아래 [섹션 추가]
- **등록 완료**: 링크 1회 표시 + [링크 복사], 메일 안내문(헬프데스크 문구 포함) + [메일 문구 복사]
- **상세**: 정보(템플릿 포함), 활동 타임라인, [재발급] [회수]

## 6. 문구 원칙

- 존댓말로 짧게 쓴다. "~했습니다 / ~해 주세요"
- 고객 화면에서는 기술 용어(토큰, 암호화, 해시)를 쓰지 않는다.
- 시간은 절대 시각과 남은 시간을 함께 쓴다: "11월 24일 14:30 · 23시간 12분 남음". 48시간 미만은 시간 단위로 쓴다.

## 7. 접근성

- 대비 WCAG AA 이상, 포커스 링 2px `--brand`
- 아이콘 버튼에는 `aria-label`을 붙인다. 복사·저장 결과는 `aria-live` 토스트로 알린다.
- 폐기 방식 카드는 `role="radio"`로, 키보드(Enter/Space)로 선택할 수 있다.
- 터치 대상 44px 이상 (고객 화면)
